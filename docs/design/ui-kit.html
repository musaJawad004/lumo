Design Rules

Check every screen against these before shipping.

Light gray background with white cards. That contrast is the whole look.
One accent color (blue). Orange only for streak flames.
One font only (DM Sans). Max weight 600. Never 700+.
Phosphor only: Light in content, Fill in the tab bar.
Glass only on floating elements, always with a 1px light border, max 2 layers.
Generous space. If a screen feels busy, remove something.
Every tap gets haptics and a 0.97 scale press.
No hard-coded values. Everything comes from useTheme() tokens.
